# 首个物理 Boss 灰盒验收（2026-08-14）

对象：磁壳搬山兽，C++ 类 `AVectorPhysicsBoss`。这轮只验 Boss 的物理合同、三阶段与基础冲锋，不验正式美术、掉落奖励数量和完整 PCG 关卡串联。

## 准备

1. 完整编译并重启 Unreal Editor。
2. 在空白关卡执行 `Tools/Greybox/setup_physics_boss_test.py`。
3. 执行 `Build → Build Paths` 后 Play。
4. Session Frontend → Automation：运行 `Vector.Boss.State` 4 项，并确认完整 `Vector.` 为 `40/40`。

## 观察顺序

### 1. 初始阶段

- Boss 为大型紫色方块，日志包含 `Boss started`、`phase=ANCHORED`、`mass=8.0`。
- 屏幕顶部显示 Boss 大血条与 `[ANCHORED]`；暴露/过载时分别更新成 `[EXPOSED]`/`[OVERLOAD]`。
- 玩家进入 18m 内后，Boss 白光预警约 0.85 秒；方向在预警开始时锁定，玩家横移不能让它中途跟踪转弯。
- 随后日志出现 `Boss ram launch ... queued=OK speed=1450 ... physicalMass=8.0`。
- 被冲锋命中仍走 `LogVectorImpact: Collision solve`，不是额外的 Boss 固定扣血。

### 2. 物理可作用

- 冲量锤、绳线枪、润滑、浮空和升空叉都可以选中 Boss；不应出现 `immune`。
- 初始质量高，所以锤击位移应小，但必须不是零。
- Boss 当前为 300 生命/90 稳定：约 20 次满蓄直接锤击可保底击杀，而接近伤害上限的物理碰撞约 6 次，目标效率差约 3 倍。
- 在白光前摇期间打出失衡，日志应出现 `Boss attack telegraph interrupted by stagger`，不能在倒地后仍突然发射旧冲锋/震荡。
- 用两只轻怪撞 Boss、让 Boss 撞硬墙，都应继续输出统一碰撞日志与伤害。
- 诱导 Boss 在水平冲锋 Active 阶段撞死轻怪，局末击杀归因应计入 `EVectorKillCause::BossRam`；普通推撞仍是 `BodyCollision`。

### 3. 暴露阶段

- 首次真正失衡，或生命降至 65% 时，Boss 变橙，日志变为 `phase=EXPOSED mass=4.0`。
- 同样强度锤击/牵引产生的位移应明显大于初始阶段。
- 重复失衡不能重复增加阶段切换计数，也不能回血回到紫色锚定阶段。
- 暴露后 Boss 在冲锋之间交替使用落地震荡：先显示约 0.95 秒红色 4m 圆形预警，再向上升空；落地必须复用 `Landing shock triggered`，不能在起跳瞬间提前伤人。

### 4. 过载与死亡

- 生命降至 30% 时 Boss 变红，日志为 `phase=OVERLOAD mass=3.0`。
- 冲锋间隔缩短，但每次冲锋后的恢复窗口更长；仍有白光前摇。
- 过载阶段仍交替冲锋/震荡，不得用无预警的瞬时 AOE 替换物理落地。
- 正式 PCG 路线中，过载会开启 BossRing 中央低摩擦区；日志为 `PCG BossRing friction ... active=YES`。Boss 死亡后输出 `active=no`，玩家离场不能继续保持低摩擦。
- 死亡进入 `DEFEATED` 后不再启动冲锋；现有敌人死亡/器官掉落/致死锤击飞尸逻辑继续工作。

## 判失败条件

- 任意阶段输出物理免疫，或受到工具后实际速度始终为零。
- 阶段切换清空已有速度、瞬移、解除已经布置的绳线。
- 冲锋方向在前摇结束前持续追踪玩家。
- 失衡中继续发射已预警但尚未发射的冲锋。
- 红圈刚出现便扣血，或 Boss 尚未落地就输出落地震荡伤害。
- 红色过载阶段反而比紫色阶段更难推动，或阶段能从后向前回退。
