# 本轮持续开发统一验收（2026-08-14）

本单覆盖 `832fae7..master` 的本轮连续提交：升空叉复验、正式三维 PCG、动态三波合同、房间门/检查点、首个物理 Boss、Boss 阶段 HUD 与撤离 Seed 摘要。

## 0. 编译前

1. 关闭 PIE。
2. 关闭 Live Coding（或退出 Unreal Editor）；新增了多个 `UCLASS/UENUM/UPROPERTY`，建议完整编译后重启编辑器。
3. VS 使用 `Development Editor / Win64` 构建 `VectorEditor`。
4. 如果失败，只发第一条真实 C++/UHT error；`MSB3073 code 6` 通常只是上游错误的汇总。

成功标准：构建成功，重启编辑器后 Python 能找到 `VectorTacticalGenerationLibrary`、`VectorPCGEncounterDirector`、`VectorPhysicsBoss`。

PIE 中若出现 `PCG encounter configuration rejected`，说明正式路线缺少 8/8 出生点、三触发器、两道门、Boss/弹药点、过载区或五段模块序列；这是硬失败，不继续测试半残合同。

## 2. 升空叉复验

运行 `Tools/Greybox/setup_physics_combo_test.py`，`Build Paths → Play`：

1. 按 `5` 选择 `LIFT`。
2. 650cm 内鼠标指向 `LiftSource`，点左键。
3. 目标出现黄色脉冲并明显升空。
4. 日志应连续出现：

```text
LogVectorLiftFork: Lift fork hit ... queued=OK ... awaiting=PendingLaunch
LogVectorMovement: Airborne launch queued: ... target=V(Z=...)
LogVectorMovement: Airborne launch consumed: ... mode=Falling check=PASS
LogVectorLiftFork: Lift verification: ... deltaZ=... peakZ=... check=PASS
```

失败标准：只有选中装备没有黄光/升空；日志 `NO target`；或 `queued=REJECTED`。

## 3. 生成正式 PCG 路线

1. 新建/打开空白关卡。
2. 运行 `Tools/Greybox/setup_tactical_pcg_preview.py`。
3. 执行 `Build → Build Paths`；这一步是动量坡与上下层可达性的硬前置。
4. 保存为新的测试地图再 Play。

生成成功日志：

```text
VECTOR_PCG: layout: seed=4417 ... modules=SafeStart>...>...>BossRing>Extraction
VECTOR_PCG: SUCCESS: deterministic PCG route built with sequential 8+8+Boss waves
```

脚本只替换 Label 以 `PCG_` 开头的 Actor。修改脚本顶部 `SEED` 后重跑，相同 Seed 的模块序列/分数必须一致。

三维结构成功标准：两个普通房中至少一个是 HardLane/HeightShelf 高度配方，BossRing 有中央落地区和两级弹药台；玩家和怪能经宽缓动量坡到达上层。OpenBowl/SlickCross 故意保持平地。高度房必须能复现“高层怪坠入低层怪群/冲锋线→落地或身体连锁”，删掉高度后该路线消失；仅增加绕路和观景台视为失败。

怪物与模块结合成功标准：每只生成怪输出 `PCG enemy slot: ... markerZ=... spawnZ=... nav=PASS archetype=...`。`HeightShelf` 的重怪/冲锋怪在上层，`HardLane` 的冲锋怪在低层直线、重怪在上层，`SlickCross` 的重怪占低摩擦十字、冲锋怪从平地侧翼切入。上层非冲锋怪先白闪 0.65 秒并输出 `Enemy drop telegraph`，再输出 `Enemy drop attack ... queued=OK` 扑向下层；前摇中锤击/牵引应输出 `telegraph interrupted`。所有生成点 `nav` 必须 PASS。

## 4. PCG 完整路线

按以下顺序判断，不要只看最终能否杀完：

1. 开局 HUD：`SEED 4417 | WAVE 0/3 | SafeStart`、`CONTRACT: ENTER THE HUNT`，场内无活动敌人。
2. 进入第一房：日志 `room=0`，生成 8 怪，HUD `WAVE 1/3`。
3. 第一房未清空：第一道红门必须阻挡。
   - 若敌人坠入虚空，Z 低于 -300 后必须立即输出 `Enemy void recovery ... ledgerAction=LETHAL_DAMAGE`，器官回收到原出生安全点，遭遇 `remaining` 在同一时刻减一；不能等待世界 KillZ。直接销毁仍由 `recovery=COUNTED` 兜底。
4. 清空第一房：HUD 显示 `ROOM CLEAR - ADVANCE`，门日志 `locked=no collision=OFF`；合同不能完成。
   - 同时必须输出 `PCG room exit verified: wave=1 ... check=PASS`。OpenBowl/HardLane 的两翼撞击墙之间保留 700/650cm 主通道；玩家沿场地中央必须能穿过，接收墙不能代替门继续封路。
5. 穿门进入第二房：此时才生成第二批 8 怪，总合同累计为 16。
6. 清空第二房并穿第二道门：生成 Boss+2 轻怪，总合同累计为 19。
7. 每次进房都有 `Player checkpoint updated`；在第二房/Boss 场死亡，应在当前房入口复活且速度为零。
8. Boss 与所有怪全部死亡：输出 `Dynamic encounter sealed`、`Contract completed ... defeated=19`、撤离门 `collision=OFF`。
9. 进入绿色撤离区：输出原有狩猎摘要，以及：

```text
Hunt PCG summary: seed=4417 modules=SafeStart>...>BossRing>Extraction
```

### 玩家坠入虚空

- 从第一房、第二房和 Boss 房分别走下无地板区域。
- 玩家低于当前检查点 450cm 后，应立即出现 `Player void recovery: ... encounterLedger=UNCHANGED`，随后出现 `Player died -> respawn ... velocity=V(0) mode=Walking`。
- 玩家必须回到当前房入口，而不是整个关卡起点；血量按现有死亡规则回满，钩索、蓄力、升空叉和残余速度全部清除。
- HUD 的本波剩余敌人数不得因玩家坠落变化；若反复坠落、卡在空中或借坠落穿过锁门，均为失败。

## 5. Boss 专项

也可单独运行 `Tools/Greybox/setup_physics_boss_test.py` 快速测 Boss。

- 初始紫色 `[ANCHORED]`、300 HP、物理质量 8；工具必须有效但位移小。
- 首次失衡或 65% HP：橙色 `[EXPOSED]`、质量 4，位移明显增大。
- 30% HP：红色 `[OVERLOAD]`、质量 3，正式 PCG BossRing 中央低摩擦区开启。
- 冲锋：白光约 0.85 秒，方向锁定后不追踪玩家；日志 `queued=OK speed=1450`。
- 震荡：暴露后进入攻击轮换；红色 4m 圈约 0.95 秒 → Boss 升空 → 落地后才出现 `Landing shock triggered`。
- 升空爆发：橙色圆环与向上箭头约 0.9 秒 → 范围内玩家和小怪按质量获得向外、向上的真实速度；日志 `Boss aerial burst target ... queued=OK`。
- 怪物弹药：过载阶段出现从一只小怪指向锁定落点的红色抛物线；前摇结束后小怪沿三维弹道飞出，日志 `Boss ammo arc launch ... error=... queued=OK`。前摇时把该怪打失衡或打离 Boss，应输出 `Boss ammo arc disarmed`，Boss 不能凭空补发投射物。
- 三维绳线：分别命中高台与低地的两只怪，绳长按空间距离计算；侧向锤击后摆动不应被压回水平面，日志动量检查仍需 PASS。
- 在冲锋/震荡前摇中打出失衡：日志 `Boss attack telegraph interrupted by stagger`，旧攻击不能延迟发射。
- Boss 死亡：低摩擦区关闭并恢复区内角色摩擦；不再发起攻击。

## 6. 物理红线

整轮出现以下任一情况即失败：

- Boss 输出 `immune` 或工具命中后实际速度恒为零；
- 阶段切换清速度、瞬移、断开玩家已布置的绳线；
- 震荡在落地前造成伤害；
- 房间切换的 `remaining=0` 提前完成合同/打开撤离门；
- 相同 Seed 重跑得到不同模块序列；
- 高度模块的动量坡 Build Paths 后仍不可达，或任一出生日志 `nav=FAIL`；
- 同时活动敌人超过 8（当前三波分别为 8、8、3）；
- 复活保留死亡前速度、绳索或动作锁；
- Boss 死后玩家仍永久保持低摩擦。
