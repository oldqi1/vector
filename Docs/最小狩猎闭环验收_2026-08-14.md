# 最小狩猎闭环验收（2026-08-14）

本轮目标不是做永久养成，而是把一局灰盒狩猎闭合成：进入固定遭遇 → 击杀并收集器官 → 清场 → 出口开放。下面每项都有画面与日志双重成功标准。

## 0. 编译与布置

1. 完全退出 Unreal Editor 后编译 `VectorEditor | Win64 | Development`；本轮新增了 `UCLASS/UENUM`，不要用仍开启的 Live Coding 顶替完整编译。
2. 重启编辑器，在目标关卡运行 `Tools/Greybox/setup_greybox_arena.py`。
3. Output Log 必须出现：
   - `GREYBOX: preflight passed`；
   - `spawned contract exit`；
   - `SUCCESS: ... 10 enemies ... west contract exit`。
4. 执行 `Build → Build Paths`，保存关卡，再进入 PIE。
5. Session Frontend → Automation 搜索 `Vector.`：应注册 **39 项**，全部通过、`0 Failed`。

若生成脚本提示找不到 `/Script/Vector.VectorContractExit`，说明编辑器仍加载着旧模块；退出编辑器重新完整编译再运行脚本。

## 1. 遭遇初始化

进入 PIE 后先不要攻击：

- 左上角显示 `ORGANS: 0`；
- 下方显示 `CONTRACT: HUNT 10 / 10`；
- 西侧边界中央是红光封锁门，玩家与敌人都不能穿过；
- 门上方屏幕投影标签显示红色 `EXIT LOCKED - CLEAR ALL`；
- 日志出现 `Encounter started: state=ACTIVE total=10`；
- 门日志出现 `Contract exit locked ... remaining=10`。

成功标准：数字必须与脚本生成的 10 只敌人一致。若显示别的数字，先检查关卡里是否残留非 `GA_` 的 `VectorEnemy`。

## 2. 普通击杀、掉落与拾取

普通击杀一只敌人，不要让最后一击成为飞尸锤击：

- 敌人死亡位置出现带绿光、旋转并上下浮动的球形器官；
- 合同剩余数从 `10 / 10` 变成 `9 / 10`；
- 日志依次能找到 `Enemy organ drop` 与 `Encounter enemy defeated: remaining=9 total=10`；
- 接触器官后器官消失，`ORGANS: 0` 变成 `ORGANS: 1`；
- 日志出现 `Organ pickup consumed ... total=1`。

成功标准：每只敌人最多掉一个，接触一次最多加一，合同数字不会因拾取再减少。

## 3. 致死锤击飞尸掉落

先把一只敌人打到下一锤可击杀，再让致死锤把它打向另一只怪或墙：

- 生命归零后尸体仍按锤击动量飞行，不在原地立即消失；
- 合同剩余数在死亡时减少一次；
- 器官应出现在飞尸首次撞怪/撞墙的位置，而不是起飞点；若始终没撞到物体，则最多约 1.75 秒后在最终位置掉落；
- 日志包含 `Lethal launch active`、`Lethal launch impact`、`Enemy organ drop`；
- 同一具飞尸不能出现两次 `Enemy organ drop`。

成功标准：飞尸仍可撞伤活怪，随后只留下一个可拾取器官。

## 4. 清场与实体出口

击杀全部 10 只敌人：

- 最后一次递减到 `0 / 10`，随后 HUD 变为绿色 `CONTRACT COMPLETE - EXIT OPEN`；
- 日志只出现一次 `Contract completed: defeated=10 elapsed=... exit=OPEN`；
- 日志出现 `Contract exit unlocked ... collision=OFF`；
- 西侧红色门体消失，状态灯转绿；
- 门上方标签同步变为绿色 `EXIT OPEN`；
- 玩家能穿过原门位置，走到墙外的短平台上。

成功标准：少杀一只时绝不能开门；清场后必须能实际穿过，而不只是 HUD 改字。器官不要求全部拾取才开门——当前合同验证的是“完成狩猎”，器官是本局资源。

## 5. 撤离结算

清场开门后走到墙外短平台上的绿色圆形区域：

- HUD 中央显示 `HUNT COMPLETE - ORGANS SECURED: N`，其中 N 等于进入前的 `ORGANS`；
- 日志各出现一次 `Hunt extraction completed: organs=N` 与 `Extraction completed: player=... organs=N`；
- 随后出现 `Hunt run summary: elapsed=... defeated=10/10 organs=N collection=...%`，并立即打印击杀归因汇总；
- 触发区随后关闭碰撞，重复走动不会再次结算；
- 结算完成后即使通过调试方式碰到遗漏器官，账本也不会再增加，并输出 `hunt already extracted`。

成功标准：没有清场时不能撤离；清场不等于结算，必须穿门进入绿色区才锁定资源。

## 6. 升空叉专项（当前唯一尚未实测的旧项）

运行 `Tools/Greybox/setup_physics_combo_test.py`，使用标记为 `LiftSource` 与 `LandingNeighbor` 的两个静止靶：

1. 按 `5` 选择 `LIFT`，鼠标指向 `LiftSource`，在 650cm 内点左键。
2. `LiftSource` 必须明显离地，日志必须出现 `Lift fork hit ... queued=OK`；黄色向上箭头可见。
3. 它落地时，邻近靶应被震荡扣血/推动，日志出现 `Landing shock triggered` 与 `Landing shock`。
4. 再按 `4` 选择 `FLOAT` 给源靶施加浮空孢子，动作恢复后切回 `5` 重试；滞空时间应明显变长。
5. 稳定重型靶单次升空可能达不到 600cm/s 落地震荡阈值，这是预期；轻型靶或先打失衡的重型靶必须能触发。

成功标准：真正进入 Falling、垂直速度按质量递减、落地只触发一次震荡；不能只原地顿一下，也不能同时误报水平 `Wall collision`。
