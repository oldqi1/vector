## 一、项目起源与方向决策

### 1.1 为什么转向

原项目《万相星体》(Morphorbit，球面径向重力动作游戏) 因**"设计文档远超开发进度"**被用户放弃：
球面/径向重力/履脊兽复杂度高，实现与验证成本失控。用户提交《冲量荒原》设计案 v0.1，
裁决**重做为平面俯视角物理动作游戏**（名称暂定），核心原则改为：**轻设计 → 原型验证 → 尽快开发**。

### 1.2 两个关键决策（2026-08-13）

| 决策 | 内容 |
|---|---|
| 3D 门槛 | 保留 3D 但降为**平面级**：垂直轴高低差（挑飞/下砸/高低台），参考 The Ascent / Midnight Fight Express；替代原球面审计宪章 |
| 工程承接 | **新建工程**（`C:\workspace\Vector\Vector`），Morphorbit 可复用 C++ 移植，不重写 |

### 1.3 三项硬约束（平面级门槛，替代原球面宪章）

| 约束 | 平面级定义 |
|---|---|
| 3D | 垂直轴改变行动关系（挑飞/下砸/高低差），俯视不因看不清高度失误 |
| PCG | 地形模块组合 + 物理战术评分，改变玩家站位与装备选择 |
| 物理 | 质量三档 + 稳定/失衡 + 碰撞连锁，可预测、可主动利用 |

### 1.4 设计案 v0.1 核心（存档于 `Crown/Documentation/01_Design/Current/冲量荒原_设计案_v0.1_暂定方向.md`）

- **一句话概念**：程序生成的异星荒原中猎杀生物，破坏稳定性、改变质量/抓地力/运动状态，把怪物撞向怪物完成连锁狩猎
- **宣传句**：怪物不是沙包，是你的弹药
- **核心循环**：接合同 → 进生态区 → 物理连锁击杀 → 采器官 → 制造装备 → 挑战更高危生态区
- **敌人状态机**：稳定 → 失衡 → 物理运动 → 碰撞/坠落 → 倒地 → 起身
- **装备**：冲量锤/双端绳线枪（由原引力钩方向重构）/升空叉/重压器/锚定盾/压缩地雷 + 调质器 + 碰撞反应组件 + 护甲核心
- **保底原则**：物理击杀比磨血快 2~3 倍，但不成为唯一解（物理不能成软锁）

## 二、开发历程（按阶段）

### S01 基础框架 + 稳定/失衡移植（2026-08-13）

- 用户亲自用 UE 向导建工程（模块名 `Vector`）；旧骨架移到 `旧文件\` 仅参考
- 移植：`UVectorStabilityComponent`（四态 Stable→Unbalanced→Downed→Rising，数值直搬 60/20-30/1.5）
- `UVectorImpactMath`：平面化闭合速度→失衡量（去球面 GravityCenter）
- 6 项 Automation 测试全过（用户编辑器 GUI 实测）
- 基础框架：固定 55° 俯角相机 + WASD + 鼠标 Yaw + 运行时 EnhancedInput

### S02 受控冲量 + 冲量锤（2026-08-13）

- `UVectorCharacterMovementComponent`：受控目标速度队列（QueueWorldVelocityOverride / QueueDirectionalVelocityOverride）
- 共享动作阶段 `EVectorActionPhase`（Idle→Windup→Active→Recovery，**全项目唯一**，DEBT-01 红线落地）
- `UVectorImpulseHammerComponent`：左键蓄力→释放推目标+扣稳定度；`AVectorTestDummy` 可推测试靶（三质量档）
- **动量模型修正**（用户实测"重物也飞很远"）：PushFactor 速度系数 → **动量定理 Δv = 冲量 ÷ 相对质量**（I=1750，轻 1.25/中 2.5/重 5.0）
- 制动精确解：UE 指数摩擦 + 线性制动，轻 12m / 中 4m / 重 1.2m（10:3:1）

### S03 碰撞连锁（2026-08-13）

- `UVectorImpactCollisionComponent`：撞目标（伤害+动量传递）/ 撞墙（自反噬）/ 落地震荡（AOE）
- 碰撞伤害公式：`(速度-300) × 0.05 × 质量系数 × 类型系数`，硬上限 50
- 只有冲量驱动的物理运动才结算碰撞伤害（正常行走互挤不伤友军）

### S04 敌人三型（2026-08-13）

- `AVectorEnemy` 基类 + `AVectorEnemyController`（NavMesh 寻路，绕墙不卡墙）
- 三型：跳囊虫（轻快群）/ 甲壳犀（重慢）/ 角槌兽（冲锋：预警 0.5s → 1600 冲量 → 冷却 4s）
- 失衡/被推飞期间 AI 让路（暂停路径跟随，不清冲量）

### S05 生命/死亡 + 灰盒场景（2026-08-13）

- `UVectorHealthComponent`：核心 100 血；碰撞伤害扣生命+同步扣稳定度
- 敌人死亡 → 销毁（含孤儿 AIController 清理，修复"杀完怪掉帧"）
- `Tools/Greybox/setup_greybox_arena.py`：8000×8000 场地 + 6 模块 + 11 敌 + NavMesh 一键生成
- 失衡脱锚质量表（轻 1.0/中 1.5/重 2.0）+ 碰撞质量系数（0.8/1.0/1.4）

### 快轨调校系列（2026-08-14）

| 调校 | 内容 |

## 三、关键技术根因（最高价值复盘）

### 3.1 "移动中怪被锤只顿一下"——三层根因链

| 层 | 现象 | 根因 | 修复 |
|---|---|---|---|
| ① | 冲量被追击速度拖慢（-461+1400=939） | 叠加语义 | **替换语义**：沿冲量方向分量 = 冲量速度，垂直分量保留 |
| ② | 残留加速度拉回 | RequestDirectMove 拦截不够，`Acceleration` 跨帧残留 | CalcVelocity 冲量期间清 `Acceleration` + `ConsumeInputVector()` |
| ③ | **数值对但怪不动** | UE 5.8 `RequestDirectMove` 写 `RequestedVelocity` + `bHasRequestedVelocity`，AI 让路后残留 true，`ApplyRequestedMove` 每帧 `Velocity = MoveVelocity` 覆盖 | CalcVelocity 冲量期间清 `bHasRequestedVelocity` + `RequestedVelocity` |

**教训**：点状修补（只挡"新请求"）不够，必须审视 UE 的全部速度写入路径（含成员变量残留）。

### 3.2 "两只紧挨怪满蓄推不飞"

- 一维模拟（`Tools/collision_chain_1d_sim.py`）证明公式层正确（B 应获 538cm/s 滑 2.6m）
- 根因：动量传递 40% 太低 → 撞击者保留 60% 继续飞 → 追上目标反复碾压（推着走而非撞飞）
- 修复：0.85 保龄球式动量守恒

### 3.3 "打飞了又飞回来"（攻击组件干扰物理）

- 根因：攻击组件独立 Tick 不检查物理状态，被推飞途中仍触发扑击 → 反向冲量替换飞行冲量
- 修复：攻击组件 Tick 开头检查 `IsImpulseDriven`/`IsStaggered`——物理状态优先，中断攻击

### 3.4 其他已记录修复

- UE `bRunPhysicsWithNoController` 默认 false → 无 Controller 靶子物理停摆（加 true）
- 灰盒方块半埋地 → 中心抬高自身半高
- 冲量锤 Overlap 漏检 Block 响应 → 改 SweepMultiByChannel
- 孤儿 AIController 残留掉帧 → 敌人死亡时销毁控制器
- 本机 ZenServer 异常 → 测试一律编辑器 GUI（Session Frontend），不用命令行无头跑
