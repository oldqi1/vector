# 冲量荒原 Demo：30 小时逐小时工作表（2026-08-17）

> 当前唯一执行排期。
> **30 小时能做出的不是完整“对外试玩 Demo”，而是可分发的定向机制验证包。**
> 30 小时可达：能独立启动、能打包、约 20 分钟跑完完整路线、风格统一的灰盒，并尽可能向普通玩家可理解的试玩 Demo 靠近。
> 硬交付：**第 30 小时结束前必须提供实际可启动的打包文件**，不能只交源码、Editor 地图或日志。
> 基础红线：排期压缩不得破坏 [`PCG_3D物理玩法基础框架.md`](PCG_3D物理玩法基础框架.md) 中的确定性 Seed、战术电路、3D 删除测试和统一物理合同。

---

## 1. 交付范围

最终包应包含一条约 12–20 分钟的完整路线：

```text
启动与操作提示
→ 普通房：矢量枪、远程实体弹与基础连锁
→ 清场三选一：先选一个改变下一房规则的模块
→ HeightShelf 高压房：水平动能→垂直换向→落点→砸落兑现
→ 磁壳搬山机 Boss：结构、实体弹药与物理反击
→ 核心/器官结算与撤离
```

交付对象首先是同行、开发者朋友和能理解“机制验证包”的测试者；但操作提示、风格、反馈和包体完整性按尽可能接近普通玩家试玩的标准处理。

### 本轮必须有

- 可冷启动的 Development 包；
- 一条完整房间—成长—Boss—撤离路线；
- 两种远程怪与实体弹药；
- 最小但成立的高度电路；
- 清房、开门、虚空回收、Boss 出生均无软锁；
- 统一灰盒配色、攻击预警、命中/结构/落点反馈；
- 操作卡、已知问题和版本说明。

### 本轮不承诺

- 正式机械模型与完整骨骼动画；
- 第二/第三 Boss；
- 腐蚀 DOT、完整商店、跨局制造；
- Boss 顶部井口与高处绳线锚点；
- 完整设置菜单、键位重绑、手柄、本地化；
- Shipping 发行质量、Steam 页面和宣传片。

## 4. 时间不足时的裁剪顺序

从上到下依次裁剪：

1. 额外音频数量；
2. 非关键后处理和镜头反馈；
3. 三选一的正式 UI 包装，保留现有选择功能；
4. HeightShelf 第二种接收器，保留两条路线本身；
5. 非阻塞数值精调。

不得裁剪：

- 首包、RC 和最终包；
- 完整路线；
- 清房、开门、虚空、寻路和 Boss 出生修复；
- 攻击预警、落点真实性与结构变化反馈；
- 操作入口和退出方式。

## 5. 30 小时完成定义

### 完成

- 有可发送的压缩包和可执行文件；
- 独立冷启动成功；
- 约 12–20 分钟完成普通房、HeightShelf、成长、Boss 和撤离；
- 核心 3D 高度链至少自然发生一次；
- 远程实体弹、结构破坏、清房和成长均能被玩家看见；
- 3 次 RC 关键路线无崩溃和软锁；
- 已知问题诚实列出。

### 不等于完成

- Editor 中能 Play；
- Automation 全绿但没有包；
- 有包但必须安装工程、运行脚本或手动补怪；
- 只有高度房好玩，整局路线没有闭合；
- 画面统一但攻击、落点和结构变化读不懂。

30 小时结束时，应把它称为：

> **风格统一、可独立运行、具备完整狩猎路线的定向机制验证包；已经朝对外试玩 Demo 前进，但不冒充内容与美术完成度已经达到公开发行标准。**
