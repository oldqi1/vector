# 美术采购评估与免费动画补救（2026-08-17）

> 定位：资产授权与后续美术管线参考，不是当前 30 小时执行排期；排期以 `Demo30小时逐小时工作表_2026-08-17.md` 为准。
> 触发：用户询问「购买公开商业模型能否缩短时间」。
> 核心结论：**这个项目采购模型几乎没有收益，真正的时间金矿是你已经躺在 `ArtSource/` 里、但没被用起来的带动画 FBX。**
> 性质：只读评估 + 排期修订，未修改工程代码。

---

## 1. 关键发现：现有素材本来就带动画

| 项 | 事实 |
|---|---|
| 素材包 | `ArtSource/QuaterniusAnimatedMonsterPack` |
| 授权 | **CC0 1.0 Universal**（公共领域，商用免授权、免署名） |
| 官方页面 | 明确提供 **FBX + OBJ + Blend 三种格式，4 只怪物各自带动画** |
| 本地实际文件 | **只有 `.obj` + `.mtl`**，缺 FBX |
| 导入脚本 | `Tools/Art/import_prototype_monsters.py` 硬编码 `.obj`，且 `import_as_skeletal = False`、`FBXIT_STATIC_MESH` |
| 结果 | 4 只怪物在引擎内是**静态网格，零动画** |

**这意味着当前「怪物无动画」不是资源缺失，而是导入路径选错了。**只需重新下载同一个 CC0 包的 FBX 版本并改导入配置，即可零成本获得骨骼与动画。

映射关系（已在 README 中定义）：

```text
Bat      -> 轻型跳跃怪
Skeleton -> 冲锋怪
Slime    -> 四锚重型目标
Dragon   -> 磁壳 Boss
```

## 2. 三条路线工时对比（怪物动画）

| 路线 | 工时 | 成本 | 判定 |
|---|---|---|---|
| 自制骨骼 + 动画 | **30h+**（4 只 × 绑定 3h + 动画 5h） | 0 | 不可行，吃光全部预算 |
| 采购商业动画怪物包 | **3–5h**（挑选 1h + 导入清理 1h + 重定向 1.5h + 命名 1h） | 付费 | 可行但非最优 |
| **重导入现有 CC0 FBX** | **1.5–2.5h** | **0** | **推荐，比采购更快** |

结论：**在怪物动画这一项上，采购不比手里的资源更快，只会更慢**（多出挑选与风格统一成本）。

## 3. 采购真正值得花钱的地方

采购的价值区间不在模型，而在两处：

| 项 | 自制 | 采购 | 净省 |
|---|---|---|---|
| Niagara VFX | 8–10h | 2–3h | **约 6h** |
| HUD / 撤离结算 UI | 5h | 2h | **约 3h** |
| **合计** | | | **约 9h** |

预算建议：**$0–60**。

### 渠道优先级

1. **手上的 CC0 Quaternius FBX**（0 元）——最高优先，今天就做。授权已验证、风格已定、含动画。
2. **Fab 免费区 + UE 官方 Niagara 内容**（0 元）——拖尾、冲击波、破碎，够用约 70%。
3. **付费风格化 VFX 包 $20–40**——唯一值得掏钱的项，直接决定「成熟感」。
4. **UI / HUD kit $15–25**——撤离结算界面性价比高。
5. **Kenney / Quaternius 模块化环境**（免费）——接 PCG 铺场，与怪物同风格。

### 明确不买

怪物模型、Boss 模型、写实角色、纯动画专包、完整项目模板、Megapack。

## 4. 采购技术门槛（俯视 3D 物理游戏专属）

若确实要买带骨骼资产，必须同时满足：

- **模型与动画同包同骨骼**，拒绝纯动画包（非人形怪物重定向失败率极高）；
- **动画集至少六段**：Idle / Walk / Run / Attack / Hit / Death；
- **Root Motion 必须关闭**——本项目移动由物理驱动，带 Root Motion 要逐段拆；
- **必须自带可用 PhysicsAsset**——这是本项目最特殊的硬门槛，物理 Boss 要吃布娃娃与约束，商业包的 PhysicsAsset 普遍敷衍，重调一次 2–3h，等于把省下的时间还回去；
- **UE 5.3+ 且不依赖插件**，材质不引用外部 Substrate/自定义节点；
- **1 uu = 1 cm，Z-up，Scale 1.0**（Quaternius 常见 0.01 缩放，导入时需统一）；
- **单图集单材质**——俯视看不见细节，多材质纯亏 DrawCall。

## 5. 最容易踩的坑

| 坑 | 说明 |
|---|---|
| 写实 / 高模包 | 俯视只看剪影和顶面，法线贴图 100% 浪费，还要为统一风格返工整套材质。看着最省，实际最费 |
| Megapack / 完整模板 | 浏览、导入、命名、剔除常超 4h，形成「资产债」 |
| 带 Blueprint 角色控制器的包 | 与已有物理角色冲突，拆解成本高于自制 |
| 风格锁定 | 买了某一家就得全项目跟随，中途混搭必崩 |
| 挑选时间黑洞 | 单人开发最大隐形消耗。**每类资产浏览硬性封顶 45 分钟**，超时即自制或放弃 |

## 6. 修订后的美术工时分配（14h）

原方案美术 10–12h 且无动画；修订后 **14h 且含动画**，因为动画来源变成了免费现成资产。

| 时长 | 任务 |
|---|---|
| 1.5h | 下载同包 FBX，重写导入脚本为 Skeletal，统一 Skeleton + 共享 AnimBP |
| 2.0h | PhysicsAsset / 布娃娃与受击反馈调优（物理游戏手感核心） |
| 3.0h | 统一 Lookdev：5 色调色板 + 后处理 + 描边/轮廓光 + 地面明度压暗 |
| 2.5h | Niagara：矢量枪弹道、绳线、动能球撞击（买包做基底） |
| 2.0h | HUD + 撤离结算界面 |
| 1.5h | 环境铺陈接 PCG |
| 1.0h | 可访问性：威胁色走色盲安全方案 + 文字缩放 |
| 0.5h | 资产命名审计 |

剩余 16h 留给玩法修正、音频、菜单、打包与验证。

## 7. 采购解决不了什么（诚实说明）

买不到：

- **视觉一致性**
- **俯视可读性**
- **本项目独有机制的 VFX 语言**（结构破坏、动量传递）
- **手感**

「成熟」与否，约八成取决于 Lookdev 与 VFX 那 5.5 小时——那是必须自己做的部分。采购只能替你跳过「从零建模」，而这一步你本来就已经免费跳过了。

---

## 8. 立即可做的第一件事

从 `https://quaternius.com/packs/animatedmonster.html` 下载同一个 CC0 包的 **FBX 版本**，放入 `ArtSource/QuaterniusAnimatedMonsterPack/`，然后把 `Tools/Art/import_prototype_monsters.py` 改为：

- 源文件后缀 `.obj` → `.fbx`
- `import_as_skeletal = False` → `True`
- `mesh_type_to_import` 改为 `FBXIT_SKELETAL_MESH`
- 开启 `import_animations`
- 复核 `import_uniform_scale`（OBJ 用的是 100.0，FBX 需实测确认）

这一步约 1.5 小时，收益是四只怪物全部获得动画——**在 30 小时预算下，这是单位时间回报最高的一步。**
