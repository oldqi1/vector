# 绳线枪重构 · 墙面牵引 / 双怪对撞 P1.5 规格卡

> 状态：**已冻结并进入实现**（2026-08-14）
> 本文覆盖旧的“稳定距离约束/失衡拉回”和早期“旋转持续扫击伤害”提案。
> 初版仍复用 `UVectorGravityHookComponent` 类名，避免角色默认子对象与资产迁移。

## 1. 一句话机制

> 绳线枪只做“连接、单向张力与卷扬”：打墙把玩家拉过去；手动两发连接两只怪，以无弹力绳制造长半径扫击，之后再收绳制造真实碰撞。

职责分离：**锤提供动量，绳线改变运动关系，质量决定运动比例，现有碰撞系统结算伤害。**

## 2. 输入与状态

### 第一发命中静态墙

1. 玩家按 `2` 选择绳线枪，再按住左键，沿鼠标投影到角色水平面的方向命中静态墙面（35cm 墙面扫掠容错）；
2. 玩家与命中点连接并自动收绳；
3. 径向速度指向锚点，原有切向速度保留，因此允许自然摆动；
4. 松开左键或达到安全停止距离后断开，保留玩家当前速度。

### 第一发命中怪物

1. 怪物成为端点 A；
2. 进入 2 秒第二发窗口，松开左键不取消；
3. 第二次点击左键，由玩家手动瞄准另一只怪物 B；
4. 不允许自动选最近目标，不允许 A=B、隔墙连接或超过最大配对距离；
5. 选择期间占用 ActionLock，超时/死亡/遮挡时安全取消。

### 第二发命中怪物

1. 建立 A↔B 单条活动绳；
2. 配对提交后立即释放 ActionLock，绳线成为世界状态；
3. 初始目标绳长等于连接距离；绳子松弛时不施力，绷紧时只限制外张，不产生弹簧回弹；
4. 先进入 1.5 秒锤击布置窗口，HUD 提示 `HAMMER NOW`；按 `1` 切回锤子不会拆线，此时卷扬暂停；
5. 捕获到锤击注入的切向角动量后进入 2 秒 `WIDE SWING`，保持长绳扫击半径；摆锤结束后才恢复卷扬；
6. A/B 两端互撞、撞墙、死亡、超距、遮挡或超时后断开；端点擦碰第三只怪只暂停收绳 0.12 秒，不断绳；
7. 仍选中绳线枪时再次点击左键可手动剪断。

## 3. 物理模型

设两端位置为 `xA/xB`，速度为 `vA/vB`，质量为 `mA/mB`。

- 共同质心速度：`Vcm = (mA·vA + mB·vB) / (mA+mB)`；
- 目标绳长为 `ℓ`：当 `r < ℓ` 时无约束；当 `r ≥ ℓ` 时只截断向外径向速度，允许自由向内运动；
- 平面单位质量角动量：`h = ((xB-xA) × (vB-vA)).Z`；
- 绳长为 `r` 时，相对切向速度：`vt = h/r`；
- 角速度：`ω = h/r²`。

所以：

- 没有切向相对速度时，两怪不会凭空旋转，只沿连线靠近；
- 已有切向动量时自然产生弧线/摆动；
- 绳长减半且未触发安全上限时，相对切向速度约增至 2 倍、角速度约增至 4 倍；
- 轻端承担更大速度变化，重端更接近共同质心；
- 每帧解算保持共同质心平面总动量不变；约束不反向推开端点，因此没有弹簧振荡；卷扬机收绳允许增加相对动能，但切向速度必须钳制。

收绳不得把“已经更快靠近”的径向速度降低。新注入的锤击/冲锋切向动量应被绳线捕获。

## 4. 伤害与连锁

- 绳线本身不产生伤害；
- 没有逐帧伤害、扫击冷却字典或额外伤害公式；
- 端点撞怪/墙时完全复用现有 `UVectorImpactCollisionComponent`；
- 身体首次接触事实先通知绳线断开，随后碰撞组件结算一次伤害与反弹；
- 端点撞第三只怪时照常结算碰撞并短暂停绳，随后继续牵引；A/B 互撞后的反弹仍可形成后续连锁；
- 击杀归因仍使用现有 Body/Wall 分类，初版不增加 HookSweep 等新来源。

## 5. 初版限制

| 参数 | 初值 | 用途 |
| --- | ---: | --- |
| 射程 | 1800cm | 墙面/怪物第一、第二发 |
| 第二发窗口 | 2.0s | 超时清空 A |
| 最大配对距离 | 1600cm | 防跨房间连接 |
| 玩家收绳速度 | 1500cm/s | 墙面位移 |
| 双怪卷扬速度 | 260cm/s | 降低抱团速度，扩大摆锤撞到第三只怪的时间窗口 |
| 锤击布置窗口 | 1.5s | 配对后暂不收绳，留出转向/站位并完成一次 0.8s 满蓄锤 |
| 长半径摆锤 | 2.0s | 捕获侧向角动量后暂停卷扬，让双怪组合横扫怪群 |
| 最大相对切向速度 | 1800cm/s | 防短绳数值爆炸 |
| 配对最大持续 | 6.0s | 配合单向张力和较慢卷扬，覆盖最大配对距离 |
| 绳枪共享冷却 | 0.60s | 墙钩结束、选怪超时、空枪或双怪断绳后均进入 CD |

灰盒阶段不做弹匣/材料消耗：物理工具需要反复试验，先用单绳、窗口、射程、速度上限和冷却控制。

## 6. 反馈

- 黄色线：玩家↔墙面锚点；
- 青色线/圆：已选端点 A，等待第二发；
- 洋红线：活动双怪绳；
- 绿色球：质量加权共同质心/预计相撞区域；
- HUD：`SELECT SECOND MONSTER` / `WALL REEL` / `PAIR RETRACTING`；
- 日志定期输出 `distance / h / omega / momentum=PASS`。

## 7. 放行验收

1. 墙面按住能拉玩家，松开后至少保留 0.55 秒低制动惯性，停止点不穿墙；
2. 两只静止轻怪不凭空旋转，并在接近中点处相撞；
3. 轻+重的相撞点明显靠近重端；
4. 有切向初速度时出现自然弧线，绳长缩短后 `omega` 增加；
5. 每次绳线解算日志为 `momentum=PASS`；
6. A/B 互撞或撞墙后只有一条断绳日志和一套现有碰撞伤害日志；第三者擦碰不得误断绳；
7. 绳线无持续伤害，反弹后仍可继续触发普通碰撞连锁；
8. 第二发超时、目标死亡、静态遮挡、超距和玩家重生均不残留端点或 ActionLock；
9. 配对完成后其他装备可立即开始；
10. 完整 `Vector.` Automation 零失败。

## 8. 明确不做

- Chaos 多绳段模拟、缠墙和绳结；
- 系统强制旋转；
- 绳线扫击持续伤害；
- 自动选择第二只怪；
- 多条同时活动绳；
- 原型期弹药经济。
