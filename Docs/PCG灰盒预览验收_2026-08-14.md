# 正式 PCG 灰盒预览验收（2026-08-14）

这一版同时验证“生成结果是否提供物理战术”和最小运行时路线。编辑器中用 `TargetPoint` 保存确定性出生位；PIE 时 `AVectorPCGEncounterDirector` 依次激活 8 怪、8 怪、Boss+2 轻怪，任何时刻都不超过 8 个活动敌人。

## 生成

1. 编译项目并重启 Unreal Editor（新增了反射类，Live Coding 不足以稳定刷新）。
2. 新建或打开一个空白关卡。
3. `Tools → Execute Python Script`，选择 `Tools/Greybox/setup_tactical_pcg_preview.py`。
4. 执行 `Build → Build Paths`。
5. 输出日志应包含 `VECTOR_PCG: layout:` 和 `SUCCESS`，且没有 `VECTOR_PCG FAILED`。

默认 `SEED = 4417`。改脚本顶部 Seed 并重跑即可换布局；脚本只清理 `PCG_` 前缀 Actor。

## 成功标准

- World Outliner 中顺序存在 `SafeStart`、两个普通遭遇模块、`BossRing`、`Extraction`。
- 玩家出生在 SafeStart，周围没有敌群标记；最末端存在绿色撤离区。
- 每个普通遭遇模块都能肉眼指出发射源、碰撞接收器和恢复空间。
- 整局至少出现一处绳线枪摆动空间、一处高度差，以及硬墙接收器或低摩擦路径。
- BossRing 有中央 Boss 点、两个补充怪点、四角立柱和高台，不是一块空平地。
- PIE 开始为安全观察期，HUD 显示 `WAVE 0/3` 且场内没有活动敌人；沿连接路进入第一房时才输出 `PCG room entered ... room=0` 与 `PCG wave activated: wave=1 spawned=8`。
- HUD 右上角显示生成 `SEED` 与当前 `WAVE 1/3`；换房后递增，不能在同一波内来回跳号。
- 每次进入新房日志输出 `Player checkpoint updated`；在第二房/Boss 场故意死亡，应在当前房入口复活，而不是回最初 SafeStart。复活后速度为零、绳索/动作锁清空。
- 第一房清空后第二房才生成，合同在房间切换的 `remaining=0` 瞬间不能完成或开门。
- 第一/第二房出口各有红色波次门；清空当前房后对应门消失、绿灯亮且碰撞关闭，日志输出 `PCG wave gate ... locked=no collision=OFF`。穿过门后的触发区才生成下一房，不能提前进入未来空房或在远处预生成 AI。
- 第二房清空后生成 `AVectorPhysicsBoss + 2` 只轻怪；三波总合同为 19，全部清空后才输出 `Dynamic encounter sealed`、`Contract completed` 并打开撤离门。
- Boss 进入红色 `OVERLOAD` 时中央低摩擦区才启用并显示青色边界；Boss 死亡后区域关闭，仍在区内的玩家/怪物摩擦必须恢复。
- 撤离区前有红色合同门和窄通道，未清场不能从门侧绕过；清场后门变绿/解除碰撞并允许结算。
- 撤离结算除原有 `Hunt run summary` 外还应输出 `Hunt PCG summary: seed=... modules=...`，其 Seed 与 HUD 一致、序列与生成日志一致。
- 相同 Seed 连续运行两次，日志里的 `modules=` 序列与 `score=` 完全相同。
- 在 Seed `1–32` 中任选几个，至少能看到两种不同的普通遭遇模块组合。
- Session Frontend → Automation 搜索 `Vector.PCG.Layout`：4 项全部通过；加入 Boss 状态与动态遭遇测试后完整 `Vector.` 当前应为 `40/40`。
