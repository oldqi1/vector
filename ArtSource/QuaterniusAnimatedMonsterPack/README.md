# Quaternius Animated Monster Pack

Source: https://quaternius.com/packs/animatedmonster.html

License: CC0 1.0 Universal. The original `LICENSE.txt` is included beside the
source files. These OBJ files are temporary Demo silhouettes; gameplay collision,
mass and structure logic remain on the Vector actor components.

Prototype mapping:

- Bat -> light hopper
- Skeleton -> charger
- Slime -> four-anchor heavy
- Dragon -> magnet-shell Boss

Run `Tools/Art/import_prototype_monsters.py` from Unreal Editor once to import
deterministic assets under `/Game/Vector/Art/PrototypeMonsters`.
